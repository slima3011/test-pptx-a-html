What the Skill Does

Converts HTML documents to PowerPoint presentations (.pptx) with three conversion modes:

  • text — Parse HTML into native, editable PPTX elements
  • image — Screenshot HTML for pixel-perfect rendering
  • auto — Automatically selects the best mode

Key Features

  • Excellent Hebrew / RTL language support
  • Custom fonts, font sizes, and background colors
  • Split slides by CSS selector (section, article, .slide, hr)
  • URL input support
  • Stdin pipe support
